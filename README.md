# Dream Travel Destinations

A React application showcasing my travel bucket list, built with Vite. This site highlights the destinations I dream of visiting, my travel aspirations, and the motivations behind each choice.

## Links
- **GitHub Repository:** [github-link](https://github.com/ddbdndnsdncxsn/travel)
- **Live Website:** [deployment-link](https://regal-biscotti-ec737f.netlify.app/)

## Features
- **Header Section:** Contains a title and tagline about my travel aspirations.
- **About My Travel Dreams Section:** A brief paragraph describing my passion for travel and exploration.
- **Destinations List Section:** Showcases my top dream destinations with details such as country, continent, main attractions, and reasons for visiting.
- **Travel Goals Section:** Lists my travel-related goals to inspire future adventures.

## Run Locally
To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ddbdndnsdncxsn/travel.git

2. **Navigate to the project directory:**

   ```bash
   cd travel

3. **Install dependencies:**

   ```bash
   npm install

4. **Start the development server:**

   ```bash
   npm run dev

5. **Open your browser and navigate to:**
    ```bash
    http://localhost:5173
